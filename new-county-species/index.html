What species were newly recorded here?

Search any iNaturalist place ID and date range. The detector compares the species recorded in that window with earlier records for only those taxa.

Set the search

Place and period

Enter a place ID from the URL of an iNaturalist place page. This works for counties and any other iNaturalist place.

By default, iNaturalist’s verifiable observations (Needs ID and Research Grade) are included; casual observations are excluded.

Method

  1. CollectAll qualifying species-level taxa in the chosen period.
  2. DeduplicateKeep each exact species taxon once.
  3. Check historyCheck only those period taxa for an earlier qualifying record, in compact batches.
  4. Link recordsAttach an actual qualifying iNaturalist observation to every new species.

A result is new to iNaturalist’s place records under these filters—not proof that the species is biologically new to the county or region.
